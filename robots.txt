# Some pages on this site are deliberately kept out of search results. That is
# done by a noindex meta tag inside each of those pages, never by this file.
#
# A noindex tag only works if the crawler is ALLOWED TO READ the page. Blocking a
# folder here stops crawlers ever seeing the tag, and the bare address can then
# still be listed in search with no description — with no way to remove it.
#
# So do not add Disallow lines to keep a page out of results. Put a noindex tag
# in the page instead. Conversely: removing a noindex tag makes a page findable.
